# 更新日志 - 多文件类型知识库向量化

> 实现日期：2026-06-01  
> 改造目标：文档上传后自动向量化环节支持 MD / TXT / PDF / Word 四种格式，提取层与分片层解耦。

---

## 一、改造前现状

| 项目 | 说明 |
|------|------|
| 支持格式 | `.txt`、`.md`（及前端 `.markdown`） |
| 读取方式 | 统一 `Files.readString()`，按纯文本处理 |
| 分片逻辑 | 单一 `DocumentChunkService`，Markdown 标题感知 |
| 分片参数 | `max-size: 800` 字符，`overlap: 100` 字符 |

## 二、架构设计

### 2.1 提取层与分片层解耦

```
上传文件 → VectorIndexService
              ↓
       DocumentProcessorRegistry（按扩展名路由）
              ↓
    ┌─────────┬─────────┬─────────┬─────────┐
    │   MD    │   TXT   │   PDF   │  Word   │
    │Processor│Processor│Processor│Processor│
    └────┬────┴────┬────┴────┬────┴────┬────┘
         │ extract │ extract │ extract │ extract
         ↓         ↓         ↓         ↓
    Markdown   PlainText   Pdf      PlainText
    ChunkStrategy ChunkStrategy ChunkStrategy ChunkStrategy
         ↓         ↓         ↓         ↓
              List<DocumentChunk>
                    ↓
         DashScope Embedding → Milvus
```

### 2.2 开源组件

| 组件 | 用途 |
|------|------|
| **Spring AI `PagePdfDocumentReader`** | PDF 按页提取（底层 Apache PDFBox） |
| **Spring AI `TikaDocumentReader`** | Word 提取 / PDF 回退（底层 Apache Tika） |
| **Java NIO `Files.readString`** | MD / TXT 纯文本读取 |

## 三、各文件类型：提取 + 分片说明

### 3.1 Markdown（`.md` / `.markdown`）

| 阶段 | 实现 |
|------|------|
| **提取** | `Files.readString` UTF-8，整文读入 |
| **分片策略** | `MarkdownChunkStrategy` |
| **分片步骤** | ① 按 `#` ~ `######` 标题切章节 → ② 章节内按 `\n\n` 切段落 → ③ 超过 800 字符合并段落后切分，相邻分片重叠 100 字符（尽量在 `。/?！` 处截断） |
| **元数据** | 章节标题写入 `metadata.title` |

### 3.2 纯文本（`.txt`）

| 阶段 | 实现 |
|------|------|
| **提取** | `Files.readString` UTF-8 |
| **分片策略** | `PlainTextChunkStrategy` |
| **分片步骤** | ① 按 `\n\n` 切段落 → ② 超过 800 字符切分，重叠 100 字符 |
| **元数据** | 无特殊元数据 |

### 3.3 PDF（`.pdf`）

| 阶段 | 实现 |
|------|------|
| **提取** | 优先 `PagePdfDocumentReader`（每页一个 `TextBlock`）；失败时回退 `TikaDocumentReader` 整文提取 |
| **分片策略** | `PdfChunkStrategy` |
| **分片步骤** | ① 每页为一个逻辑块 → ② 单页超过 800 字符时，页内按段落 → 字符切分 |
| **元数据** | `metadata.pageNumber`（页码）、`metadata.title`（如「第 3 页」） |

### 3.4 Word（`.doc` / `.docx`）

| 阶段 | 实现 |
|------|------|
| **提取** | `TikaDocumentReader` 提取纯文本 |
| **分片策略** | `PlainTextChunkStrategy`（与 TXT 共用） |
| **分片步骤** | ① 按 `\n\n` 切段落 → ② 超过 800 字符切分，重叠 100 字符 |
| **元数据** | 无特殊元数据 |

### 3.5 全局分片参数（`application.yml`）

```yaml
document:
  chunk:
    max-size: 800    # 单分片最大字符数
    overlap: 100       # 相邻分片重叠字符数
```

## 五、核心代码片段

### 5.1 路由入口（`DocumentProcessorRegistry`）

```java
public List<DocumentChunk> process(Path file) throws Exception {
    return resolve(file.toString()).process(file);
}
```

### 5.2 提取 + 分片编排（`AbstractDocumentProcessor`）

```java
public List<DocumentChunk> process(Path file) throws Exception {
    List<TextBlock> blocks = extract(file);          // 提取层
    return getChunkStrategy().chunk(blocks, file.toString());  // 分片层
}
```

### 5.3 PDF 按页提取（`PdfDocumentProcessor`）

```java
PagePdfDocumentReader reader = new PagePdfDocumentReader(resource,
    PdfDocumentReaderConfig.builder().withPagesPerDocument(1).build());
List<Document> documents = reader.read();
// 每页 → TextBlock，metadata.pageNumber = 页码
```

### 5.4 Word 提取（`WordDocumentProcessor`）

```java
TikaDocumentReader reader = new TikaDocumentReader(new FileSystemResource(file.toFile()));
List<Document> documents = reader.read();
// 整文 → TextBlock → PlainTextChunkStrategy
```

### 5.5 索引流程（`VectorIndexService.indexSingleFile`）

```java
// 删除旧向量 → 提取+分片 → 逐片 Embedding → 写入 Milvus
List<DocumentChunk> chunks = chunkService.chunkDocument(path);
for (DocumentChunk chunk : chunks) {
    List<Float> vector = embeddingService.generateEmbedding(chunk.getContent());
    insertToMilvus(chunk.getContent(), vector, buildMetadata(...), chunk.getChunkIndex());
}
```

## 六、配置与使用

### 6.1 允许上传的扩展名

```yaml
file:
  upload:
    path: ./uploads
    allowed-extensions: txt,md,pdf,doc,docx
```

```bash

# PDF

# Word
curl -X POST http://localhost:9900/api/upload -F "file=@report.docx"
```
